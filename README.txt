Publish free with Cloudflare Pages:
1. Sign in at https://dash.cloudflare.com/
2. Open Workers & Pages.
3. Choose Create application, then Pages.
4. Choose Direct Upload (or upload assets).
5. Upload the contents of this folder, or upload the ZIP.
6. Choose a project name such as edgemontgarage if available.
7. Cloudflare will publish it at a pages.dev address.
